How did the machine decide?

This is a nearest-centroid classifier: it picks the closest group average.

  1. Scale: map each feature to 0?1 using the fixed input ranges. Then average the scaled values separately for each label.
  2. Measure: find the straight-line distance from your scaled gem to each scaled average.
  3. Predict: choose the smaller distance. Equal distances mean a tie.

scaled RI = (RI ? 1.400) / 1.400
scaled SG = (SG ? 2.200) / 3.900
distance = ?((scaled gem RI ? scaled average RI)? + (scaled gem SG ? scaled average SG)?)

RI spans 1.400 and SG spans 3.900. Scaling both to 0?1 gives equal importance to the same fraction of each range, so SG?s larger numeric range does not dominate. The limits stay fixed when you change the examples. Distances are model distances, not percentages. With only a few examples, guesses can easily be wrong.

A clue to a diamond—not proof

Diamond typically has RI about 2.42 and SG about 3.52. These are useful clues, but this model only compares examples. It cannot authenticate a gem or distinguish natural from laboratory-grown diamonds.

Diamonds are crystals too! Here, “Crystal” means our non-diamond classroom examples, not one mineral with fixed properties. A gemologist uses additional tests to identify a real stone.
